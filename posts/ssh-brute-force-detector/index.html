SSH Brute Force Detector - A beginner's guide

SSH Brute-force Detector

Even though it says ssh brute-force detector, I would say it is more like a simple pattern recognizer tool. I’ve been diving in to SOC work and one thing is clear, it is not just triaging the tickets. Automtion and Scripting is heavily used to make repetitive tasks easier, and also to make tasks like log analysis bearable. I came up with the idea when I was doing some log analysis exercise on LetsDefend, and as much as there are other tools available, it’s always better to know how to script to so you can make customizations.

Logic Flow

This is a very basic script so there aren’t much steps to take. We mostly use regex pattern to identify/flag potential IPs and their count. We define a few things like whitelisted IPs, a threshold to define how many attempts are concerning, and a time window as typically brute-force attacks would spam a lot in less amount of time. The most important thing here is to define the base pattern which would typically involve the IP address and date + time. The pattern I came up after some googling is (\w+ +\d+ \d+:\d+:\d+).*from (\d+\.\d+\.\d+\.\d+)

Main Code Logic

There is really no function to define, the logic is to open the log file, read each line, extract IP and date, time. See if it incldues “Failed Password” and then compare it against the threshold and time windwo defined. For my code, it will flag all the IPs which have more than 5 failed attempts in a specific time window.

THRESHOLD = 5
WHITELIST = {"127.0.0.1", "192.168.1.1"}
LOG_FILE = "Linux_2k.log"
PATTERN = re.compile(r"(\w+ +\d+ \d+:\d+:\d+).*from (\d+\.\d+\.\d+\.\d+)")


failed_attempts = defaultdict(list)
blocked_ips = set()

#logic for parsing and extracting IP and datetime
with open(LOG_FILE, "r") as f:
    for line in f:
        if "Failed password" not in line:
            continue
        
        match = PATTERN.search(line)
        if not match:
            continue
        
        timestamp_str = match.group(1)
        ip = match.group(2)
        
        timestamp = datetime.strptime(timestamp_str, "%b %d %H:%M:%S")
        timestamp = timestamp.replace(year=datetime.now().year)
        
        failed_attempts[ip].append(timestamp)
        
for ip, timestamp in failed_attempts.items():
    if len(failed_attempts[ip]) >= THRESHOLD:
        if ip in WHITELIST:
            continue
        elif ip in blocked_ips:
            continue
        
        blocked_ips.add(ip)
